# Retrofix NextJS

Remake of my Netflix clone [Retrofix](https://github.com/caffeinated-pixels/retrofix) using Next.js & Typescript. Still a WIP, but you can [see it in action over on Netlify](https://retrofix-nextjs.netlify.app).

Migrating the app to Next.js was more work than I thought it be, but I've refactored much of the logic and restructured the project along the way. It's always fun revisting old projects and trying to figure out what the heck you were thinking at the time 🤣

## Technologies & libraries used

- Next.js (v14, app router)
- Typescript
- Styled-components
- Fuse.js (fuzzy searching)
- Firebase authentication (with next-firebase-auth-edge )
